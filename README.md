# Credit Risk & Economic Analysis

Credit-risk modeling and economic data analysis (previously mislabeled as an NLP project — it's actually about credit scoring, not NLP).

## Why this exists
Explores credit risk prediction using historical credit data, alongside economic indicator analysis.

## Tech stack
Python, Jupyter Notebook

## How to run
1. `pip install -r requirements.txt`
2. `python main.py` to run the main pipeline, or `python economic_analyze.py` for the economic analysis piece
3. `credit_model.pkl` / `home_credit_model.pkl` are trained models used for scoring
4. `EDA.ipynb` and `C2M3_Assignment.ipynb` contain exploratory analysis

**Note:** this repo was renamed from `NLP_2026` — the original name didn't match its actual content.
